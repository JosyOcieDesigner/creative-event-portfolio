# Creative Event Portfolio

Video-first portfolio starter for Josy Prasetya.

## Files
- `index.html` — main page
- `style.css` — visual styling
- `script.js` — video gallery data

## Add another YouTube video
Open `script.js`, then replace a placeholder:

```js
{
  title: "Project Name",
  category: "Event • Creative Direction",
  youtubeId: "YOUR_YOUTUBE_VIDEO_ID"
}
```

For a link like:
`https://youtu.be/p5H_neI8nSA`

the video ID is:
`p5H_neI8nSA`

## Publish with GitHub Pages
Upload these files to a repository, then enable GitHub Pages from the repository settings using the main branch.


The gallery is now prepared for 24 video projects.
